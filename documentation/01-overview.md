# Garage Builder - Project Overview

## Introduction
Garage Builder is a comprehensive solution for managing and visualizing garage construction projects. The application provides tools for designing, pricing, and managing garage construction projects with a modern web interface.

## Features
- Interactive 3D garage visualization
- Project management and tracking
- Material and cost estimation
- User authentication and authorization
- Responsive web interface

## Technology Stack
- **Frontend**: Streamlit
- **Backend**: Node.js with Express
- **Database**: MySQL
- **AI/ML**: Ollama for AI-powered features
- **Containerization**: Docker
- **GPU Acceleration**: NVIDIA CUDA for AI workloads

## Project Structure
