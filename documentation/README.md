## Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Vardan57555/garage-builder.git
   cd garage-builder
   ```

2. Start the application:
   ```bash
   make start
   ```

3. Access the application:
   - Frontend: http://localhost:8501
   - API: http://localhost:5003
